# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | ✅ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in flowmcp, please report it privately by emailing:

**sreejap974@gmail.com**

Include the following in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

## What to expect

- You will receive an acknowledgement within **48 hours**
- We will investigate and keep you updated on the fix progress
- We will credit you in the release notes unless you prefer to remain anonymous
- We aim to release a fix within **7 days** for critical issues

## Scope

The following are in scope:
- Code in the `python/` and `java/` directories
- GitHub Actions workflows in `.github/workflows/`
- Any dependency we ship

Thank you for helping keep flowmcp and its users safe.
