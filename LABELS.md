# Labels

This file documents all GitHub labels used in this repository.
Labels help categorize issues and pull requests so contributors can find work that matches their skills.

## How to apply labels

- Maintainers apply labels when triaging issues and PRs
- Contributors can suggest labels in their issue or PR description
- Use `good first issue` for tasks that need only 1–2 files changed with clear requirements
- Use `help wanted` when you need the community's input on a design decision
